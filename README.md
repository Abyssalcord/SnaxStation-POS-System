# About the project

A robust, console-based Java Point of Sale (POS) and inventory management system built for SnaxStation, an artisanal pastry shop. Designed with clean object-oriented principles, multi-class architecture, and secure administrative controls.

# Key Features

- Live Stock Management: Real-time stock tracking with cumulative cart validation to prevent overselling.

- Customer Loyalty Tiers: Automatic points calculation (1 pt per P50 spent) unlocking Pastry Connoisseur (5% off) and SweetTooth Mania (10% off) discounts.

- Flexible Ordering: Dine-In and Take-Out order type selection.

- Kitchen Order Routing (KOT): Automatic generation of unique 4-digit ticket IDs for kitchen tracking.

- Admin Security Controls: Password-protected End-of-Day (EOD) sales revenue summaries and secure system exit guards.
